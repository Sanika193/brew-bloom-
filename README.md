# Brew & Bloom ☕

Brew & Bloom is a café website created as a college project using React JS and Vite.

## Features
- Attractive café homepage
- Café-themed design
- Menu and café information
- Responsive styling

## Technologies Used
- React JS
- JavaScript
- HTML
- CSS
- Vite

## How to Run
1. Download or clone this repository.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown in the terminal.
